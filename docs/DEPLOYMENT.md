# Deployment Guide

This guide explains how to build and deploy the ThinkHazard! documentation with the integrated query builder.

## Quick Start

```bash
cd docs

# 1. Generate JSON files from CSV data
python convert_csv_to_json.py

# 2. Build documentation
jupyter book build --html

# 3. Copy query builder and JSON files to build output
bash copypublic_files.sh

# 4. Preview locally
cd _build/html
python -m http.server 3100
# Open http://localhost:3100
```

## File Organization

### Source Files (docs/)

- **Data (in `public/`):**
  - `TH_ADM2.csv` - Administrative divisions (source data, committed)
  - `TH_URB.csv` - Urban areas (source data, committed)
  - `divisions_flat.json` - 43,202 divisions (generated, committed)
  - `urban_areas.json` - 2,919 urban areas (generated, committed)
  - `countries.json` - 245 countries (generated, committed)

- **Scripts (in `docs/` root):**
  - `convert_csv_to_json.py` - Generates JSON from CSV (outputs to `public/`)
  - `copypublic_files.sh` - Copies files from `public/` to `_build/html/`

- **Query Builder (in `docs/` root):**
  - `query_builder.html` - Interactive search tool

### Build Output (_build/html/)
The `_build/html/` directory contains the complete built site:
- All markdown files converted to HTML
- Query builder and JSON files copied from root
- Ready for deployment to GitHub Pages

**Note:** `_build/` is gitignored and should not be committed.

## GitHub Pages Deployment

### Recommended: GitHub Actions (Automated)

Jupyter Book provides a command that automatically generates a complete GitHub Actions workflow.

#### Step 1: Generate the GitHub Actions Workflow

```bash
cd docs
jupyter book init --gh-pages
```

The command will ask you two questions:
- **What branch would you like to deploy from?** → Enter `master`
- **What would you like to call the action?** → Enter `deploy.yml`

This will create `.github/workflows/deploy.yml` with everything configured.

#### Step 2: Add Custom Build Steps

The generated workflow builds the book automatically, but we need to add our custom steps for JSON generation and file copying.

**Edit `.github/workflows/deploy.yml`** and add these lines right **after** the Python setup step and **before** the build step:

```yaml
      # Add these custom steps before "Build the book"
      - name: Generate JSON files from CSV
        working-directory: docs
        run: python convert_csv_to_json.py

      # The build step is already generated by jupyter-book init
      # After the build step, add:
      - name: Copy query builder and JSON files to build
        working-directory: docs
        run: bash copypublic_files.sh
```

Your final workflow should look like:
```yaml
# ... (auto-generated header)
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: 3.x

      # ADD THIS:
      - name: Generate JSON files from CSV
        working-directory: docs
        run: python convert_csv_to_json.py

      # Auto-generated build step:
      - name: Build the book
        run: |
          pip install jupyter-book
          jupyter book build --html docs

      # ADD THIS:
      - name: Copy query builder and JSON files to build
        working-directory: docs
        run: bash copypublic_files.sh

      # ... (rest is auto-generated)
```

#### Step 3: Configure GitHub Pages

1. Go to your repository **Settings** → **Pages**
2. Under **Source**, select **GitHub Actions**
3. Save the settings

#### Step 4: Commit and Push

```bash
git add .github/workflows/deploy.yml
git commit -m "Set up GitHub Pages deployment"
git push
```

Once pushed, GitHub Actions will automatically build and deploy to `https://gfdrr.github.io/thinkhazard/`

#### Step 5: Monitor Deployment

After pushing:
1. Go to your repository's **Actions** tab
2. Look for the `deploy.yml` workflow running
3. Once complete (green checkmark), your site is live!
4. Visit `https://gfdrr.github.io/thinkhazard/`

### Alternative: Manual Deployment with ghp-import

If you prefer manual deployment:

```bash
# Build everything
cd docs
python convert_csv_to_json.py
jupyter book build --html
bash copypublic_files.sh

# Install ghp-import if needed
pip install ghp-import

# Deploy to gh-pages branch
ghp-import -n -p -f _build/html
```

Then enable GitHub Pages in repository settings to deploy from the `gh-pages` branch.

## Updating Data

To update the division or urban area data:

1. Update the CSV files in `public/`:
   - `TH_ADM2.csv` - Administrative divisions
   - `TH_URB.csv` - Urban areas

2. Regenerate JSON:
   ```bash
   python convert_csv_to_json.py
   ```

3. Rebuild and deploy as normal

## Query Builder

The query builder provides an interactive interface for finding division codes:

- **Features:**
  - Search 43,202 administrative divisions
  - Search 2,919 urban areas
  - Tab interface to switch between search modes
  - Auto-generated API endpoints for each location
  - Copy-paste ready URLs

- **Access:**
  - Local: http://localhost:3100/query_builder.html
  - GitHub Pages: https://gfdrr.github.io/thinkhazard/query_builder.html

## Troubleshooting

### "jupyter book start doesn't work"
Don't use `jupyter book start` - it doesn't properly serve the JSON files. Use a simple Python HTTP server instead:
```bash
cd _build/html
python -m http.server 3100
```

### "Query builder shows 'Error loading data'"
Make sure you've run `copypublic_files.sh` after building:
```bash
bash copypublic_files.sh
```

### "JSON files are out of date"
Regenerate from source CSVs:
```bash
python convert_csv_to_json.py
```
